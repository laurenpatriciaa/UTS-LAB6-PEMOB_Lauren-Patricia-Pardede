# Deskripsi Aplikasi
  Aplikasi ini dirancang untuk menguji pengetahuan pengguna dalam subjek pemrograman Flutter dan Dart melalui format kuis pilihan ganda.
  - Masukkan nama: Pengguna dapat memasukkan nama mereka sebelum memulai quiz.
  - Kuis pilihan ganda: Menjawab serangkaian pertanyaan seputar Flutter dan Dart.
  - Skor dan review jawaban: Melihat skor akhir secara langsung dan mempelajari jawaban yang benar melalui fitur review interaktif.
  - Dark Mode: Pengguna dapat mengaktifkan Dark Mode.
